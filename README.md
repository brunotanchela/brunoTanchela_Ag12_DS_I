# 🌐 Meus Sites Favoritos

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![Status](https://img.shields.io/badge/status-concluído-brightgreen?style=for-the-badge)

Página web simples, feita em HTML puro, que reúne meus sites favoritos com o logotipo e um link direto para cada um.

---

## 📋 Sobre o projeto

Atividade prática do curso de **Desenvolvimento de Sistemas (ETEC)**, criada para praticar a estrutura básica de uma página HTML: títulos, imagens e links. A página lista cinco sites — YouTube, Spotify, Chess.com, Notion e Instagram — cada um com seu logotipo e um link que abre em uma nova aba.

---

## 🗂️ Estrutura do projeto

```
meus-sites-favoritos/
├── index.html
└── imgs/
    ├── youtube.png
    ├── spotify.png
    ├── chess.png
    ├── notion.png
    └── instagram.png
```

---

## 🚀 Como executar

Abrao arquivo `index.html` em qualquer navegador (dois cliques sobre o arquivo ou botão direito → *Abrir com*).
